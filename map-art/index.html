About the maps and your downloads

The artwork uses real OpenStreetMap data in OpenMapTiles vector tiles supplied by OpenFreeMap. Place search is provided by Photon. The browsing map uses OpenStreetMap tiles. Searches and selected map areas are sent to these services to load the map; your design is saved in this browser.

SVG downloads contain real vector paths, not enlarged map screenshots. PNG size is measured along its longest edge. At 300 DPI, a 4800-pixel edge prints at 16 inches / 40.6 cm. Actual print appearance depends on your printer, paper, and color settings. PNG fixes the typography used on this device; SVG text can vary with the fonts installed where it is opened.

Map services and local map detail can vary. If a service is unavailable, your last saved print remains available. Exact coordinates work without place search. Select a wider area for a simpler map; closer crops reveal more street detail. Artwork includes required attribution to OpenStreetMap contributors and OpenMapTiles. Sources and license notes.
